# Arnav Banthia – Personal Portfolio

A retro, gamified personal portfolio website built with HTML, CSS, and JavaScript, styled entirely like a classic Minecraft inventory and world interface!

Live Site: arnavbanthiapersonalportfolio.github.io

🚀 Features

Interactive Minecraft Block: Click the grass block on the home screen to mine it and unlock retro achievements!

Game-Style Hotbar Navigation: A fixed bottom hotbar that highlights your current section as you scroll.

Player Stats & XP Levels: Sections displaying background info, projects, skills with XP progress bars, and an "Inventory" of interests.

Responsive Design: Fully optimized for both desktop and mobile viewports.

🛠️ Built With

HTML5 – Structured markup

CSS3 – Custom styling, retro fonts (Press Start 2P & VT323 via Google Fonts), and grid layouts

JavaScript (Vanilla) – Interactive mining counter, achievement toasts, and smooth scroll spy behavior

📦 Project Structure

├── index.html       # Main application file containing structure, styling, and scripts
└── README.md        # Project documentation


💻 Running Locally

To test or run this portfolio on your local machine:

Clone or download this repository:

git clone https://github.com/arnavbanthia03/arnavbanthiapersonalportfolio.github.io.git


Open the project folder.

Double-click index.html or open it using your preferred code editor (like VS Code with the Live Server extension).
